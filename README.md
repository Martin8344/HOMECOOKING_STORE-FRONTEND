# HOMECOOKING STORE - Frontend

A modern, responsive e-commerce frontend for a home-cooking store. Built with HTML, CSS, and JavaScript.

🔗 **Live Demo:** https://martin8344.github.io/HOMECOOKING_STORE-FRONTEND/

## Features
- Responsive design for mobile, tablet & desktop
- Product listing with images and prices
- Clean and modern UI
- Interactive cart UI with JavaScript

## Technologies Used
- HTML5
- CSS3
- JavaScript

## How to Run
1. Clone the repo
2. Open `index.html` in your browser
